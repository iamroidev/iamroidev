## Email signature

See `email-signature.html` in the project root.

**Setup (2 options):**

**Option A — Paste from browser:**
1. Drag `email-signature.html` into a Chrome tab
2. Ctrl+A → Ctrl+C
3. Gmail → Settings ⚙ → See all settings → Signature → + Create new
4. Name it "Professional" → paste into the text box
5. Fix the photo if it's broken (see below)
6. Save Changes

**Option B — Upload the photo directly in Gmail (no hosting needed):**
1. Follow steps 1–4 above
2. Delete the broken image in the editor
3. Click the image icon in Gmail's toolbar → Upload → select `img/roi.jpg`
4. Resize to "Small" in the editor
5. Save Changes

**If you want the photo to load from your live site:**
- Push `img/roi.jpg` to the repo → it will be served at
