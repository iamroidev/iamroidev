## 🚀 How to Compile the LaTeX CV on Overleaf

1. Go to [Overleaf.com](https://www.overleaf.com/) (free account).
2. Click **New Project** $\rightarrow$ **Blank Project** (e.g. name it `Richard_Kwaku_Opoku_CV`).
3. Copy all code from `Richard_Kwaku_Opoku_CV.tex` and paste it into `main.tex`.
4. Click **Recompile** and download the PDF!
